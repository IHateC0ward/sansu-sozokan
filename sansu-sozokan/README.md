# 算数創造館

小学5・6年生向け、ボーダー先生と学ぶ算数EdTechサイトのNext.jsモックアップです。

## 起動
```bash
npm install
npm run dev
```
ブラウザで `http://localhost:3000` を開きます。

## 主な実装
- Next.js App Router / TypeScript
- Tailwind CSS v4
- Motion for React
- Zustand + localStorage永続化
- next-themes ダーク/ライトモード
- Lucide Reactアイコン
- Canvas APIの簡易図形アート
- 6ルート、共通ヘッダー、下部ナビ、AIガイド

## 本番化時に追加するもの
認証、DB、投稿承認、API、Three.js、問題CMS、レーダーチャート、監査ログ、保護者同意、アクセシビリティテスト。
